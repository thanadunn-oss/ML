## 2. การใช้งานที่ตั้งใจ

- **ผู้ใช้:** นักศึกษา นักวิจัย และผู้ดูแลชุดข้อมูลภาพรอยโรค (ตาม AI Project Canvas)
- **งาน:** เสนอประเภทรอยโรคจากภาพ dermoscopy เพื่อช่วยจัดหมวดหมู่ และคัดภาพที่ควรให้คนตรวจทาน
- **ไม่ใช่สำหรับ:** การวินิจฉัย คัดกรอง หรือตัดสินใจทางการแพทย์
- **ข้อมูลนอกขอบเขต:** ภาพที่ไม่ใช่ dermoscopy (เช่น ภาพครอป 3D-TBP ของ ISIC 2024 หรือภาพถ่ายมือถือ), รอยโรคนอก 7 คลาส — โมเดลจะยังตอบหนึ่งใน 7 คลาสเสมอ

## 3. ข้อมูล

- **แหล่ง:** HAM10000 (Tschandl et al., 2018, *Scientific Data*) จาก Harvard Dataverse — สัญญาอนุญาต **CC BY-NC 4.0 (ห้ามใช้เชิงพาณิชย์)**
- **จำนวน:** 10,015 ภาพ จาก 7,470 รอยโรค ใช้ครบทุกภาพ ไม่มีภาพหาย
- **แบ่งชุด:** ตาม `lesion_id` (รอยโรคเดียวกันอยู่ชุดเดียวกัน) และรักษาสัดส่วนคลาส, seed 42 → lesion รั่วข้ามชุด 0

| คลาส | dx | train | val | test |
|---|---|---|---|---|
| nevus | nv | 4,789 | 958 | 958 |
| melanoma | mel | 795 | 159 | 159 |
| keratosis | bkl | 784 | 158 | 157 |
| bcc | bcc | 366 | 74 | 74 |
| akiec | akiec | 231 | 48 | 48 |
| dermatofibroma | df | 81 | 17 | 17 |
| vascular | vasc | 98 | 22 | 22 |
| **รวม** | | **7,144** | **1,436** | **1,435** |

**ทำไมไม่ใช้ ISIC 2024:** มี 401,059 ภาพ ทุกภาพมี label ว่ามะเร็งหรือไม่ แต่ label ชนิดโรค (`iddx_3`) มีเพียง 1,065 ภาพ ใช้ทำ multiclass ได้จริง 963 ภาพ ต่ำกว่าเกณฑ์ 10,000 ภาพของกลุ่ม (ผลการทดลองชุดนั้นดู `experiment_log.md`)

## 4. เกณฑ์การเลือกโมเดล

| ประเภท | เกณฑ์ | ผลของโมเดลนี้ (val) |
|---|---|---|
| **Optimizing** | val Macro F1 สูงสุด (ในกลุ่มที่ผ่าน gate) | 0.755 |
| **Gate 1** | melanoma recall ≥ 0.50 และ precision ≥ 0.25 | recall 0.64, precision 0.56 ✓ |
| **Gate 2** | CPU latency p95 ≤ 200 ms | 40 ms ✓ |

precision ใน Gate 1 กันโมเดลที่โกงด้วยการทายทุกภาพเป็น melanoma (recall = 1.0) — พบจริงระหว่างทดสอบระบบ

## 4.1 เกณฑ์ส่งทบทวน (ใช้ใน API)

**กฎ:** ถ้าความน่าจะเป็นสูงสุด **< 0.8** → `needs_review` (เลือกจาก val โดยคนที่ 3)

| τ | ส่งทบทวน | accuracy ของภาพที่ระบบตอบเอง | melanoma ที่หลุดโดยไม่มีคนตรวจ |
|---|---|---|---|
| 0.6 | 8.1% | 0.855 | 48 / 159 |
| 0.7 | 13.1% | 0.877 | 39 / 159 |
| **0.8** | **19.6%** | **0.899** | **32 / 159** |
| 0.9 | 28.7% | 0.927 | 22 / 159 |

เหตุผล: ผู้ใช้เป็นนักศึกษา/ผู้ดูแลชุดข้อมูล ไม่ใช่งานคลินิก — 0.8 ให้ภาระตรวจ ~1 ใน 5 ของภาพ และความแม่นของภาพที่ระบบตอบเองใกล้ 90%
ค่า τ เดิม 0.6 ใช้กับโมเดล ISIC 2024 ซึ่งมั่นใจน้อยกว่า ถ้าใช้ 0.6 กับโมเดลนี้จะส่งทบทวนเพียง 8% และ melanoma หลุด 48 ภาพ
ตารางเต็ม: `docs/review_threshold_sweep.json` · ข้อจำกัด: ภาพที่โมเดลมั่นใจสูงแต่ผิดจะไม่ถูกส่งทบทวน

## 6. ข้อจำกัดที่ทราบ

1. **melanoma ↔ nevus:** melanoma ถูกทายเป็น nevus 35/159 บน test และ nevus ถูกทายเป็น melanoma 74/958 (false alarm) — เป็นรอยโรคเซลล์เม็ดสีเหมือนกัน
2. **akiec ↔ keratosis:** akiec ถูกทายเป็น keratosis 14/48 — รอยโรคมีขุยคล้ายกัน
3. **ข้อมูลไม่สมดุล:** nevus 67% ของข้อมูล; dermatofibroma/vascular มีภาพทดสอบเพียง 17/22 ภาพ ค่ารายคลาสจึงแกว่งได้มาก
4. **ใช้ได้กับภาพ dermoscopy เท่านั้น** — ไม่ได้ทดสอบกับภาพชนิดอื่น
5. **แหล่งข้อมูล 2 แห่ง** (เวียนนา, ควีนส์แลนด์) ประชากรน่าจะเป็นผิวขาวเป็นส่วนใหญ่ — ยังไม่ได้ทดสอบกับผิวสีอื่น
6. **ห้ามใช้เชิงพาณิชย์** ตามสัญญาอนุญาต CC BY-NC ของข้อมูล
